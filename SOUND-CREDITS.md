# Sound credits and L4 placeholder assets

Realistic BWR by OldGunslingerWildBill. These are deliberately silent sound-event
placeholders, created for the project on 2026-10-13. They reserve stable resource
IDs for the later synthesized sound pack; the mod does not play them in L4.

## Provenance and license

Every `.ogg` listed below was generated by
[`tools-generate-sound-placeholders.py`](tools-generate-sound-placeholders.py)
from **12,000 mono signed-16-bit PCM samples, all exactly zero, at 48,000 Hz**.
Python's standard-library `wave` module writes this procedural source. No
recording, sample library, downloaded audio, or third-party audio was copied or
bundled. All files contain the same silence, with distinct paths and stable Ogg
stream serials derived from their event IDs.

The project-authored generator, documentation, registration and generated
placeholders are supplied under the repository's existing
[`LICENSE`](LICENSE), **LicenseRef-Realistic-BWR-Source-Available-1.0**, to the
extent those terms apply. This file creates no separate license and changes no
existing attribution or third-party rights. Preserve the project's `LICENSE`
and `NOTICE` when distributing an authorized build.

Encoding used the locally installed **Blender 5.2.2 LTS, build d13f752e3b9c**,
through its synchronous Audaspace `Sound.write` interface and bundled FFmpeg
Ogg Vorbis writer. The Ogg vendor/comment identifies **Lavf62.12.100**. Encoding
parameters are mono, 48,000 Hz, float32 encoder input, Vorbis, 96,000 bit/s, and a
1,024-frame writer buffer. The input WAV remains signed-16-bit zero PCM; sample
format conversion cannot introduce a nonzero source signal. Blender, Audaspace
and FFmpeg binaries are external authoring tools and are not included in this
sound pack; they retain their own licenses.

The generator fixes each Ogg stream serial using the first four SHA-256 bytes
of `bwr:<event-path>` and recalculates Ogg page checksums. It leaves all audio
packets, Vorbis headers and granule positions unchanged. Each checked-in file
is 3,981 bytes. Each final Ogg granule is 12,000 samples (0.25 seconds).
Minecraft's pinned JOrbis decoder returns exactly 12,000 mono samples per file,
all zero. Audaspace's decoder exposes 11,872 samples because of its handling of
codec priming; those samples are also all zero. The runtime decoder's result,
not another decoder's padding convention, is the client-check expectation.

## Reproduce or verify

No Python packages or downloaded encoders are needed. Use Python 3 and the
existing Blender executable for the exact build above. From the repository
root, the generation command used on the authoring machine is:

```powershell
python .\tools-generate-sound-placeholders.py --blender 'C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe'
```

The default output directory is the repository's `assets/bwr/sounds` directory
shown above. `--output-dir <directory>` can target a separate review directory.
The script launches a separate background Blender with factory settings and
does not open, modify or save the user's current Blender scene. It generates
one zero PCM source and checks that the encoded audio decodes to nonempty,
exact-zero mono PCM before writing the sixteen files.

To independently regenerate in temporary storage and compare every byte
without overwriting the checked-in assets:

```powershell
python .\tools-generate-sound-placeholders.py --blender 'C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe' --check
```

Byte-identical checks require the pinned Blender build and encoder environment.
A deliberate encoder upgrade must regenerate, decode and audit all sixteen
files and update this provenance. Ogg stream IDs and checksums are deterministic;
the source audio contains no randomness or timestamp-dependent samples.

## Boundary for Phase Q

L4 registers variable-range `SoundEvent`s, sound definitions and subtitle keys.
It adds **no playback hooks, ticker, looping-sound engine, command, plant-state
change, alarm logic, scram action, breaker action or automatic start**. Names
such as `breaker_trip`, `scram_buzzer` and `edg_start` reserve sounds; they do not
perform those actions. Short placeholders use `stream: false`; this does not
implement looping or positional behavior by itself.

Phase Q will provide the separate `tools-generate-sounds.py` synthesizer and
replace these silent assets with authored sounds under the same event IDs.
That reviewed work owns mono positional playback, seamless pump/EDG loops,
normalized levels, speed-dependent turbine pitch, steam/SRV noise, lifecycle
cleanup and any necessary streaming choices. Playback may reflect plant state;
it must not command or protect the plant. Update this file with the synthesis
parameters, authoring provenance and applicable licenses when the silence is
replaced. Do not add unlicensed recordings or samples.

## The two rumble loops (synthesised, not silent)

`rumble_pool.ogg` and `rumble_turbine.ogg` are the exception to the placeholders above: real, audible, looping sounds, played by the rumble
(RUMBLE.md). They are generated by [`tools-make-rumble-sounds.py`](tools-make-rumble-sounds.py) from seeded noise and sine waves with numpy;
no recording, sample library, downloaded or third-party audio was used. Encoded to Ogg Vorbis (mono, 48 kHz, 96 kbit/s) by a headless
Blender 5.2.2 through its Audaspace writer, like the placeholders. 33 kB and 23 kB. Same project licence as the rest of the project's assets.
`tools-audit-sounds.py` audits them apart from the silent placeholders; `RumbleClientCheck` decodes them with Minecraft's decoder and requires them to be deep
and to loop without a step.
